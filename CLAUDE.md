# InterviewVault

A system-design and DSA study vault. The markdown under `LLD/**` and `DSA/**` is the
source of truth; `site/` is generated by `tools/build-site.mjs`, is gitignored, and must
never be hand-edited. GitHub Actions builds and deploys it to Cloudflare Pages.

## Skills

- **onboard-doc** (`.claude/skills/onboard-doc/SKILL.md`) — read this **before adding,
  moving, renaming or restructuring any document** in `LLD/**` or `DSA/**`, and before
  adding practice challenges under `content/challenges/`. It covers the collection
  layout, the heading contracts the build extracts from, mermaid and code-block rules,
  cross-linking, and the verification gates.

## Non-negotiables

- **Never edit `site/`** — it is build output. Change the markdown and rebuild.
- **Server-side code under `LLD/` is Python**; `DSA/` stays C++. Browser code stays
  `javascript`, Redis scripts stay `lua`, SQL stays `sql` — converting them would make
  the docs wrong.
- **Mermaid**: no `;` inside label or message text; quote any label containing brackets
  or parentheses. A block that will not parse fails the build.
- **Run the gates before claiming done** — CI runs the same four and a failure blocks the
  deploy:

  ```bash
  python3 tools/check-python.py
  cd tools && node render-diagrams.mjs && node build-site.mjs && cd ..
  node tools/check-site.mjs
  ```

- **Commit new files promptly.** Untracked files have been lost to `git clean` in this
  repo before; `git status --porcelain` should be empty when work is finished.
