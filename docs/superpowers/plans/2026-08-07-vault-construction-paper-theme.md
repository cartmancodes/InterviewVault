# Vault Construction-Paper Theme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-theme the InterviewVault vault pages to match the portfolio landing page's construction-paper identity, without costing the long-form doc pages their readability.

**Architecture:** One hand-written stylesheet, `tools/template/site.css`, copied verbatim into `site/assets/` by the build. The portfolio's accent tokens move from `body.portfolio` up to `:root` so both halves of the site share one vocabulary; blue retires to focus-ring duty; the vault's chrome and index surfaces take the 2px-ink cutout treatment while reading surfaces keep their hairlines. Work proceeds component by component, converting each group's `var(--blue*)` references, so the site is coherent and shippable at every commit.

**Tech Stack:** Plain CSS (no framework, no preprocessor), a small amount of inline SVG generated by `tools/build-site.mjs` (Node ESM), and Puppeteer + a static server for rendered verification.

## Global Constraints

- **Never edit `site/`.** It is build output. Change `tools/template/site.css` or `tools/build-site.mjs` and rebuild.
- **Run the five gates before claiming any task done.** CI runs the same five and a failure blocks the deploy:
  ```bash
  node tools/check-dsa.mjs
  python3 tools/check-python.py
  cd tools && node render-diagrams.mjs && node build-site.mjs && cd ..
  node tools/check-site.mjs
  ```
- **`git status --porcelain` must be empty when work is finished.** Untracked files have been lost to `git clean` in this repo before.
- **Yellow `#FFD808` is never text.** It is 1.39:1 on white. It appears only as a fill behind ink.
- **Muted text never sits on a sky band.** Even the darkened `--mut` is 3.35:1 on `--sky`. On sky bands, muted text uses `--ink-2` (4.66:1).
- **No pair may regress** against its value before this change.
- Server-side code under `LLD/` stays Python and `DSA/` stays C++. This plan touches neither.

```js
// Theme verification. Part A is pure (parses tokens, computes contrast).
// Part B renders the built site and asserts computed styles.
//   node theme-check.mjs          both parts (needs a server on :8899)
//   node theme-check.mjs --tokens Part A only
import { readFileSync } from 'fs';

const CSS = '/Users/shubhojeetchakraborty/PersonalProjects/InterviewVault/tools/template/site.css';
const CHROME = '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome';
const PUPPETEER = '/Users/shubhojeetchakraborty/PersonalProjects/InterviewVault/tools/node_modules/puppeteer/lib/esm/puppeteer/puppeteer.js';
const BASE = 'http://localhost:8899';

/* ── contrast ─────────────────────────────────────────── */
const hex = (h) => h.replace('#', '').match(/../g).map((x) => parseInt(x, 16) / 255);
const lin = (c) => (c <= 0.04045 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4);
const L = (h) => { const [r, g, b] = hex(h).map(lin); return 0.2126 * r + 0.7152 * g + 0.0722 * b; };
const ratio = (a, b) => { const x = L(a), y = L(b); const [hi, lo] = x > y ? [x, y] : [y, x]; return (hi + 0.05) / (lo + 0.05); };

/* ── token parsing ────────────────────────────────────── */
function tokens() {
  const css = readFileSync(CSS, 'utf8');
  const root = css.slice(css.indexOf(':root'), css.indexOf('}', css.indexOf(':root')));
  const out = {};
  for (const m of root.matchAll(/(--[a-z0-9-]+)\s*:\s*(#[0-9A-Fa-f]{6})/g)) out[m[1]] = m[2];
  return out;
}

// [fgToken, bgToken, minRatio, label] — later tasks append here.
export const TOKEN_PAIRS = [
  ['--ink',   '--paper',    4.5, 'prose link / body text on white'],
  ['--ink',   '--acc',      4.5, 'ink on a yellow fill'],
  ['--ink',   '--sky',      4.5, 'ink on a sky band'],
  ['--ink',   '--sky-wash', 4.5, 'body text on the page background'],
  ['--ink-2', '--sky',      4.5, 'muted text on a sky band steps up to ink-2'],
  ['--mut',   '--paper',    4.5, 'meta text on white'],
  ['--mut',   '--sky-wash', 4.5, 'meta text on the page background'],
  ['--mut',   '--acc',      4.5, 'chip count on a selected yellow chip'],
  ['--mut',   '--soft',     4.5, 'meta text on inset surfaces'],
  ['--ink',   '--acc-wash', 4.5, 'text on a hover wash'],
  ['--blue',  '--paper',    3.0, 'focus ring on white'],
  ['--blue',  '--sky-wash', 3.0, 'focus ring on the page background'],
  ['--ink',   '--sky',      3.0, 'focus ring on a sky band is ink, not blue'],
];

// Later tasks append here.
export const RENDER_CHECKS = [];

// Tokens that must be absent from :root. Task 8 fills this in once every
// reference has been converted.
export const RETIRED = [];

/* ── runner ───────────────────────────────────────────── */
let failed = 0;
const ok = (pass, label, detail) => {
  console.log(`  ${pass ? 'PASS' : 'FAIL'}  ${label}${detail ? '  — ' + detail : ''}`);
  if (!pass) failed++;
};

function partA() {
  const t = tokens();
  console.log('Part A — token contrast');
  // The retired aliases are deleted in Task 8, not here — 27 references to them
  // survive until then. RETIRED starts empty and Task 8 fills it in.
  for (const r of RETIRED) ok(!(r in t), `${r} is gone from :root`);
  for (const [fg, bg, min, label] of TOKEN_PAIRS) {
    if (!t[fg] || !t[bg]) { ok(false, label, `missing token ${!t[fg] ? fg : bg}`); continue; }
    const r = ratio(t[fg], t[bg]);
    ok(r >= min, label, `${t[fg]} on ${t[bg]} = ${r.toFixed(2)}:1 (need ${min})`);
  }
}

async function partB() {
  if (!RENDER_CHECKS.length) return;
  const puppeteer = (await import(PUPPETEER)).default;
  const browser = await puppeteer.launch({ executablePath: CHROME, args: ['--no-sandbox'] });
  console.log('\nPart B — rendered computed styles');
  const byUrl = new Map();
  for (const c of RENDER_CHECKS) {
    if (!byUrl.has(c.url)) byUrl.set(c.url, []);
    byUrl.get(c.url).push(c);
  }
  for (const [url, checks] of byUrl) {
    const page = await browser.newPage();
    await page.setViewport({ width: 1440, height: 1000 });
    await page.goto(BASE + url, { waitUntil: 'networkidle0' });
    await new Promise((r) => setTimeout(r, 800));
    for (const c of checks) {
      const got = await page.evaluate(({ sel, prop }) => {
        const el = document.querySelector(sel);
        return el ? getComputedStyle(el)[prop] : null;
      }, c);
      ok(got === c.expect, `${url} ${c.label}`, `${c.sel} ${c.prop} = ${got}`);
    }
    // no page may scroll sideways
    const oflow = await page.evaluate(() => document.documentElement.scrollWidth > document.documentElement.clientWidth);
    ok(!oflow, `${url} has no horizontal overflow`);
    await page.close();
  }
  await browser.close();
}

await partA();
if (!process.argv.includes('--tokens')) await partB();
console.log(failed ? `\n${failed} FAILURE(S)` : '\nall theme checks passed');
process.exit(failed ? 1 : 0);
```
